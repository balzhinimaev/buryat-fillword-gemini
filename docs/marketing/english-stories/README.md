# Burlive English story posters

Original promotional assets created for Telegram Stories, November 2026.

- [Overview poster](Burlive-English-Story.png): 24 chapters, 420 exercises and 24 dialogues.
- [A1–B2 topic roadmap](Burlive-English-Story-Levels.png): example topics at each stage, with a clear distinction between topic difficulty and assessed language proficiency.

The PNGs are original generated artwork, not screenshots of the app. The supplied files measure 941 × 1672 and 916 × 1717 pixels respectively. Fit the full image in the Story editor without cropping text; add a separate link sticker to <https://buryat-game.ru/webapp/>.

Editable generation briefs are included as `overview-prompt.txt` and `levels-prompt.txt`. Both images were created with the imagegen tool; the second uses the first as its visual reference. The published course content was checked against the poster's counts and level/topic labels. No proficiency certificate, automatic speaking assessment or guaranteed B2 outcome is advertised.
